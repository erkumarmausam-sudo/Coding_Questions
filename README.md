# 📋 Example Format

## 633. Sum of Square Numbers

**Difficulty:** Medium

### Problem

Given a non-negative integer `c`, determine whether there exist two integers `a` and `b` such that:

```
a² + b² = c
```

### Example

Input:
```
c = 5
```

Output:
```
true
```

Explanation:
```
1² + 2² = 5
```

---

### Approach

Use the **Two Pointer** technique.

- Start one pointer from `0`.
- Start another pointer from `√c`.
- Compare their square sum with `c`.
- Move pointers accordingly.

---

### Complexity

Time Complexity:
```
O(√n)
```

Space Complexity:
```
O(1)
```
